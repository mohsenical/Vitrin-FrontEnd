# 🛍️ فروشگاه اینترنتی | Vitrin 

یک پروژه فروشگاهی مدرن با طراحی حرفه‌ای، رابط کاربری جذاب و تجربه کاربری روان، توسعه‌یافته با استفاده از Next.js و تکنولوژی‌های روز دنیای فرانت‌اند.

## 👨‍💻 درباره پروژه

این وب‌سایت یک پلتفرم فروشگاهی با تمرکز بر نمایش محصولات و ارائه تجربه‌ای ساده، سریع و لذت‌بخش برای کاربران است. در توسعه این پروژه تلاش شده تا علاوه بر ظاهر مدرن، ساختار کدها نیز قابل نگهداری، توسعه‌پذیر و بهینه باشد.

## ✨ ویژگی‌ها

- طراحی مدرن و کاربرپسند
- رابط کاربری واکنش‌گرا (Responsive)
- مناسب برای فروشگاه‌های اینترنتی
- نمایش جذاب محصولات
- استفاده از اسلایدرهای تعاملی
- نمایش پیام‌های اطلاع‌رسانی و اعلان‌ها
- ساختار کامپوننت‌محور و قابل توسعه
- تجربه کاربری روان و جذاب

## 🧰 تکنولوژی‌ها و ابزارهای استفاده‌شده

### Core Technologies

- **Next.js** – فریم‌ورک قدرتمند مبتنی بر React
- **React** – ساخت رابط کاربری کامپوننت‌محور
- **Tailwind CSS** – طراحی سریع و منعطف رابط کاربری
- **JavaScript** – پیاده‌سازی منطق برنامه

### Libraries & Packages

- **React Icons** – استفاده از مجموعه آیکون‌های متنوع
- **Swiper** – ساخت اسلایدرها و بخش‌های متحرک
- **React Toastify** – نمایش اعلان‌ها و پیام‌های تعاملی

## 🚀 نصب و اجرای پروژه

ابتدا مخزن پروژه را دریافت کنید:

```bash
git clone https://github.com/mohsenical/Vitrin-FrontEnd.git
```

وارد پوشه پروژه شوید:

```bash
cd Vitrin-FrontEnd
```

سپس پکیج‌های موردنیاز را نصب کنید:

```bash
npm install
```

برای اجرای پروژه در محیط توسعه:

```bash
npm run dev
```

حالا پروژه از طریق آدرس زیر در دسترس خواهد بود:

```text
http://localhost:3000
```
